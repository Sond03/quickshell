### Planned

## Dependencies
- quickshell-git (probably works with normal but not tested)
- Hyprland
- Qt 6

## Installation
```sh
sudo pacman -S quickshell-git
git clone https://github.com/yourname/quickshell-config ~/.config/quickshell
```
